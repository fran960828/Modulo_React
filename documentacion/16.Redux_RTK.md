# 📘 Guía Profesional de Redux para Principiantes

---

## 1. Introducción a Redux

> **Explicación:** Redux es una librería para la gestión del estado global en aplicaciones de JavaScript. Imagina que tu aplicación es una gran empresa: en lugar de que cada empleado (componente) guarde información importante en post-its que se pierden, Redux es una "bóveda central" donde reside toda la información crítica, asegurando que todos vean la misma versión de la realidad.

```typescript
// Ejemplo conceptual sencillo (Sin librerías aún)
// El "Estado" es un simple objeto que representa la situación actual
const initialState = { counter: 0 };

// El "Reducer" es una función que decide cómo cambia ese estado basado en una acción
function counterReducer(state = initialState, action: { type: string }) {
  if (action.type === "increment") {
    return { counter: state.counter + 1 };
  }
  return state;
}
```

---

## 2. Tipos de Estado: Local vs Cross-Component vs App-Wide

Es vital saber qué batalla pelear con cada herramienta:

- **Local State:** Datos que pertenecen a un solo componente (ej. lo que escribes en un input). Se usa `useState`.
- **Cross-Component State:** Datos que afectan a un par de componentes (ej. un modal abierto/cerrado que se controla desde un botón padre). Se usa _Prop Drilling_ o Context.
- **App-Wide State:** Datos que afectan a toda la aplicación (ej. autenticación del usuario, carrito de compras, tema oscuro). Aquí brilla **Redux**.

---

## 3. ¿React Context o Redux?

- **React Context:** Ideal para datos que no cambian con mucha frecuencia (como el idioma o el tema). Si el estado cambia cada segundo, Context puede causar problemas de rendimiento en aplicaciones grandes.
- **Redux:** Diseñado para alta frecuencia de actualizaciones y aplicaciones complejas. Ofrece herramientas de depuración increíbles (Redux DevTools) y una estructura predecible.

---

## 4. El Flujo de Redux

El flujo de datos en Redux es **unidireccional** y sigue este ciclo:

1. **Store:** El almacén central de datos.
2. **Componentes:** Se suscriben al Store para mostrar la información.
3. **Dispatch Actions:** El componente "despacha" una intención (ej. "quiero borrar esto").
4. **Reducer Function:** La acción llega al Reducer, quien procesa el cambio.
5. **Mutate Store:** El Reducer devuelve un **nuevo** estado (nunca edita el anterior directamente), actualizando la "bóveda".

## 5. Funciones Core (Redux Vanilla)

Aunque hoy usamos Toolkit, es fundamental entender estas funciones base:

```typescript
import { createStore } from "redux";

// 1. Reducer: Lógica de cambio
const counterReducer = (state = { counter: 0 }, action: any) => {
  if (action.type === "increment") return { counter: state.counter + 1 };
  return state;
};

// 2. createStore: Crea el almacén central
const store = createStore(counterReducer);

// 3. store.subscribe: Ejecuta una función cada vez que el estado cambie
store.subscribe(() => {
  console.log("Cambio detectado:", store.getState()); // 4. store.getState: Obtiene el estado actual
});

// 5. store.dispatch: Envía una acción para activar el reducer
store.dispatch({ type: "increment" });
```

## 6. Provider: Conectando Redux con React

Para que React "vea" el Store, usamos el componente `Provider` de la librería `react-redux`.

```tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { Provider } from "react-redux";
import store from "./store/index"; // Tu archivo de store
import App from "./App";

const root = ReactDOM.createRoot(document.getElementById("root")!);

root.render(
  // Envolvemos la App y pasamos el store como prop
  <Provider store={store}>
    <App />
  </Provider>
);
```

## 7. useSelector y useDispatch

Estos son los Hooks que usarás el 99% del tiempo en tus componentes.

```tsx
import { useSelector, useDispatch } from "react-redux";

const Counter = () => {
  // useSelector: Extrae datos específicos del store (como un selector)
  const counter = useSelector((state: any) => state.counter);

  // useDispatch: Obtiene la función para enviar acciones
  const dispatch = useDispatch();

  const incrementHandler = () => {
    dispatch({ type: "increment" }); // Enviamos la orden
  };

  return (
    <div>
      <p>Valor: {counter}</p>
      <button onClick={incrementHandler}>Incrementar</button>
    </div>
  );
};
```

## 8. Redux Toolkit (RTK): El estándar moderno

Redux clásico era muy repetitivo (_boilerplate_). RTK simplifica todo.

### Instalación

```bash
npm install @reduxjs/toolkit react-redux

```

### Uso de `createSlice` y `configureStore`

Un **Slice** es una porción del estado global (ej. un slice para "auth", otro para "productos").

```typescript
// store/counter-slice.ts
import { createSlice } from "@reduxjs/toolkit";

const counterSlice = createSlice({
  name: "counter",
  initialState: { value: 0 },
  reducers: {
    // Aquí puedes "mutar" el estado directamente gracias a la librería Immer (interna)
    increment(state) {
      state.value++;
    },
    increase(state, action) {
      state.value = state.value + action.payload;
    },
  },
});

// Exportamos las acciones generadas automáticamente
export const counterActions = counterSlice.actions;
export default counterSlice;
```

### Configuración del Store con `configureStore`

```typescript
// store/index.ts
import { configureStore } from "@reduxjs/toolkit";
import counterSlice from "./counter-slice";

// configureStore combina múltiples reducers automáticamente
const store = configureStore({
  reducer: {
    counter: counterSlice.reducer, // Usamos el reducer del slice
  },
});

export default store;
```

## 9. Ejemplo Final: Uso profesional de la Slice

Así es como usarías todo lo anterior en un componente real con TypeScript.

```tsx
import { useSelector, useDispatch } from "react-redux";
// Importamos las acciones del slice
import { counterActions } from "./store/counter-slice";

const ProfessionalCounter = () => {
  const dispatch = useDispatch();

  // Accedemos a la propiedad 'counter' definida en configureStore
  const count = useSelector((state: any) => state.counter.value);

  const addFiveHandler = () => {
    // Usamos el método de la acción y pasamos el payload (5)
    dispatch(counterActions.increase(5));
  };

  return (
    <section>
      <h1>Contador: {count}</h1>
      <button onClick={() => dispatch(counterActions.increment())}>+1</button>
      <button onClick={addFiveHandler}>+5</button>
    </section>
  );
};
```

---

**Resumen para el éxito:**

1. Define tu **Slice** con el estado inicial y los reducers.
2. Registra ese Slice en el **Store** central con `configureStore`.
3. Envuelve tu App con el **Provider**.
4. Usa `useSelector` para leer y `useDispatch` junto con tus `slice.actions` para cambiar datos.
